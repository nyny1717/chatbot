PDF 기반 RAG 챗봇 프로토타입

코멘토 AI 에이전트 서비스 기획 개발 2차 과제로 제출하는 PDF 기반 RAG 시스템 프로토타입입니다. 사용자가 PDF 문서를 업로드하면 해당 문서의 내용을 바탕으로 정확하게 답변해 주는 AI 어시스턴트입니다.

1. 시스템 아키텍처 및 데이터 흐름
구현 환경은 로컬 환경(Windows)에서 실행되도록 구축했으며, 전체 데이터 처리 흐름은 다음과 같습니다.
PDF 문서 업로드 -> 텍스트 추출 (PyMuPDF) -> 텍스트 분할 (Text Splitter) -> 임베딩 및 벡터 DB 저장 (FAISS) -> 사용자 질문 입력 -> 유사 문서 검색 (Retriever) -> 프롬프트 결합 및 Gemini API 호출 -> 최종 답변 출력

2. 사용 기술 (Tech Stack)
언어: Python
프레임워크: Streamlit, LangChain
AI 모델 (LLM): Google Gemini (gemini-3.5-flash-lite)
임베딩 및 벡터 DB: Google Generative AI Embeddings (models/gemini-embedding-001), FAISS
문서 파싱: PyMuPDF

3. 실행 방법 및 API 키 설정

1단계. 환경 준비 및 라이브러리 설치
파이썬 가상환경을 생성하고 활성화한 뒤 터미널에 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
pip install streamlit langchain langchain-community langchain-google-genai langchain-text-splitters faiss-cpu pymupdf python-dotenv

2단계. API 키 설정
프로젝트 최상단 폴더에 .env 파일을 생성하고 본인의 구글 API 키를 입력하여 저장합니다.
GOOGLE_API_KEY=본인의_구글_API_키_입력

3단계. 프로토타입 실행
터미널에 아래 명령어를 입력하여 스트림릿 웹 인터페이스를 실행합니다.
streamlit run app.py

4. 프롬프트 엔지니어링 및 파라미터 비교 테스트

프롬프트 버전별 개선 테스트
초기 버전 (V1): 단순히 문서 내용을 바탕으로 답변하라고만 지시했으나, 문서에 없는 내용을 질문했을 때 AI가 자체 지식으로 추측하여 답변하는 할루시네이션(환각) 현상이 발생했습니다.
개선 버전 (V2): 반드시 제공된 문서의 내용에만 근거하여 답변하고, 문서에 없는 내용이라면 지어내지 말고 제공된 문서에는 해당 내용이 포함되어 있지 않습니다라고 답변하도록 제약 조건을 강화하여 환각 현상을 완벽히 방어했습니다.

청크 사이즈(chunk_size) 및 검색 파라미터 비교 실험
문서 분할 크기와 검색 설정에 따른 답변 품질 및 누락 여부를 비교하기 위해 동일한 질문(1차시부터 마지막 차시까지 각 주차별 핵심 업무 내용과 결과물을 순서대로 정리해 주세요)을 입력하여 테스트했습니다.

chunk_size=400 테스트 결과: 문서를 잘게 쪼개어 여러 위치의 조각을 동시에 검색하는 특징을 보였습니다. 이로 인해 세부 역할명은 요약되었으나, 문서 내 다른 표에 흩어져 있던 업무 제출 기한(세션일 기준 5일 이내, 7일 이내) 정보까지 함께 찾아내어 참고사항으로 보완해 주었습니다.

chunk_size=1000 테스트 결과: 한 번에 참조하는 문맥이 길어져 단일 항목의 디테일이 훨씬 풍부해졌습니다. 400일 때 생략되었던 3주차 팀 프로젝트의 4가지 세부 역할(AI Solutions Architect, AI Engineer, Cloud Engineer, Product Owner)과 협업 도구(GitHub, Slack 등)까지 누락 없이 정확하게 추출하는 것을 확인했습니다.

기타 파라미터 (chunk_overlap, k) 조정: 문맥 단절을 줄이기 위해 chunk_overlap과 검색 문서 수(k)를 함께 조정해 본 결과, 전체 요약형 질문에서는 문맥을 넓게 참조할수록 누락 없이 매끄러운 답변이 생성되었습니다.

최종 적용: 세부 문맥의 누락을 방지하고 완성도 높은 요약 답변을 제공하기 위해 최종 프로토타입에는 chunk_size=1000을 적용했습니다.

5. 사용자 입력 및 AI 응답 예시 (최종 chunk_size=1000 기준)

테스트 1. 문서 내 전체 정보 요약 (정상 추출)
사용자 입력: 1차시부터 마지막 차시까지 각 주차별 핵심 업무 내용과 결과물을 순서대로 정리해 주세요.
AI 응답: 
제공된 문서를 바탕으로 주차별 핵심 업무 내용과 결과물을 순서대로 정리해 드립니다.
1주차: 직무 에센스 강의 및 1차 개인 업무 수행 / 결과물: 1차 개인 업무 제출 및 서면 피드백 제공
2주차: 팀 프로젝트 업무 수행 및 중간 체크포인트 / 결과물: 진행 상황 공유
3주차: 2차 개인 업무 발표 및 팀 빌딩(AI Solutions Architect 등 4개 역할 분담, GitHub 및 Slack 등 협업 도구 결정, RFP 선택) / 결과물: 2차 개인 업무 제출 및 발표
4주차: 팀 프로젝트 수행 주차 (문서상 상세 세부 일정 미기재)
5주차: 팀 프로젝트 업무 제출 및 최종발표 / 결과물: 최종 결과물 제출 및 실시간 피드백 제공

테스트 2. 문서에 없는 정보 질문 (할루시네이션 방어)
사용자 입력: 이 업무 요청서를 기준으로 수료 후 취업 연계 일정과 면접 날짜를 알려주세요.
AI 응답: 제공된 문서에는 수료 후 취업 연계 일정과 면접 날짜에 대한 내용이 포함되어 있지 않습니다.
